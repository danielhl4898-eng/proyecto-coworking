# Briefing 



## **1. Contexto**



La aplicación será utilizada por equipos de hockey línea para poder gestionar la información y asistencia de sus jugadores, así como su rendimiento en partidos y entrenamientos, proponiéndoles objetivos personalizados a cada jugador para cuando acaben el año.

Esta aplicación permitirá a los equipos tener un entorno centralizado que les permitirá tener todos los documentos relacionados a cada jugador al alcance de un click, teniéndolo todo organizado.
