# Viabilidad Proyecto



### Viabilidad técnica



El proyecto es viable técnicamente, ya que no será necesario disponer de hardware extra para utilizar la página web.



### Viabilidad económica



No hace falta (aún) un presupuesto elevado para este proyecto, ya que la mayoría de herramientas que se utilizarán serán gratuitas o de código abierto.



Nos hará falta:

* Ordenador/portátil para el desarrollo (ya dispongo de ello)
* Conexión a Internet
* Sistema de control de versiones (p. ej. GitHub)





### Viabilidad operativa



La aplicación va a estar destinada a clubes de hockey línea que quieran consultar y gestionar entrenamientos, viajes, etc.



Las distintas funciones de las que dispondrá, serán fácilmente accesibles desde un navegador web para que los entrenadores puedan acceder en todo momento que les haga falta.

### Viabilidad legal



Este proyecto tendrá en cuenta la protección de datos de los jugadores/entrenadores que se registren en la aplicación.



Evitaremos almacenar datos personales innecesarios para la funcionalidad de la página web.
